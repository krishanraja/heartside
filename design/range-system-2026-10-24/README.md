## Range-wide behavior

- One source photo and one set of factual Buddy answers define the dog.
- One selected style and one sentimental-to-hilarious tone travel across all selected products. Changing gift must not reset either choice.
- Style controls the medium. Tone controls emotional/comic staging and note wording where words appear.
- Keep the approved three stops: Sentimental, Warm with a wink, Hilarious.
- Artwork may adapt composition to format but cannot silently switch style or tone. A product/style combination that fails quality checks stays unreleased; do not make a different-looking substitution without telling the buyer.
- Keep one recommended preview first. Explore styles reveals the six options. The buyer need not inspect every option or repeat their story.
- Stage changes and use one deliberate Update artwork action. Preserve the last good preview, guard duplicate requests and retain input on failure. This behavior is designed, not implemented.
- Store the settings for the set and bind every product's render to its own format, current photo/facts, style/tone and prompt revision. Changing the set makes older mismatched renders stale; ordering must wait for matching proofs.
- Exact note text remains outside the image model for production. Manual edits and tone-generated text must have explicit ownership so generation never silently overwrites a buyer's edit.
