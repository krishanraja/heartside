# Framed-print art direction, 23 October 2026

Krish approved `city-screenprint-approved-target.png` as the visual target for a new framed-print direction. It uses the existing public reference pug photo in `assets/photos/pug-autumn-leaves.jpg`, a fictional dog name, and a San Francisco scene. It is an internal concept, not a customer image, production print file or live product mockup. The companion `city-screenprint-background-concept.png` leaves the small footer blank so customer-specific words can be composed as an exact separate layer.

The chosen art direction is a refined screenprint with the recognizable dog in a meaningful city scene. The dog-voice note is small, handwritten and at lower right, with a decorative illustrated paw mark. The paw must never be described as an actual print from the customer's dog. City or meaningful place should be optional; never infer it from a shipping address.

The approved concept and blank background are 1024 × 1536 pixels. At 12 × 18 inches, that is about 85 DPI, so neither file may be sent to Printful. One 4× upscale and a deterministic footer composition have now produced a **test-only** 3600 × 5400 file in the private scratch folder. The exact note, signature and paw are composed outside the image model by `tools/print-art/`. The pixel dimensions alone do not prove physical print quality or identity preservation across customer dogs. Customer likeness at scale, turnaround, cost, and the live Teeinblue handoff remain unproven. Keep the current framed print live until these checks pass and an exact live-theme change is approved.

Image prompt for the background: edit the real reference photo into a 12 × 18 vertical, premium mid-century screenprint of the same recognizable pug in a San Francisco scene, with restrained indigo, coral, cream and gold, fine halftone texture, natural dog anatomy, no costume, and a clean 12% ivory footer for exact customer-specific text. The artwork was generated and edited with the built-in image generation tool.

An exploratory five-photo trial used the pug, a red poodle, a cream maltipoo,
a sleeping golden puppy, and an apricot poodle. All generated backgrounds were
1024 × 1536 before any upscaling. The visible breed, coat and pose cues mostly
survived, but this is the team's visual assessment, not owner-confirmed
identity. The first Seattle scene stacked landmarks into an implausible view;
the earlier San Francisco pug scene also crowds incompatible city cues. A
Seattle retry using one local cue gave a more believable neighborhood scene.
The repeatable prompt now forbids landmark collage, and a person must reject
geography or likeness mistakes on every order. These outputs are test data in
private scratch, not buyer previews or shippable files.
