# Heartside

Heartside makes gifts for people whose small dog is their person. The line is "Keep them close." The store runs on Shopify, sells to the US, and launches on 20 October 2026.

This repo holds the brief for finishing the storefront and building the launch videos. Start with docs/BRIEF.md, then docs/AD-BRIEF.md, then docs/STORE-STATE.md. The assets folder holds the logo, the watercolour heart and the hero photo.
