## Pass and stop criteria

The photographic reference was inspected directly: compact short muzzle with broad dark mask, folded dark ears with unequal visible shapes, forehead folds, fawn short coat, cream chest and curled tail. Use the source side by side for eye shape/spacing, mask boundaries, head/body proportions and left/right details. A matching breed or attractive image is insufficient. Hidden anatomy and markings remain unknown.

Score identity, facts, medium distinction and composition 0 to 2: 0 = fail, 1 = uncertain, 2 = clearly supported. A screening pass requires all four to score 2, a human side-by-side identity verdict, and no critical defect. Uncertainty is REVIEW, not PASS. Blindly shuffle style labels for the comparison and ask whether each medium is visibly distinct; six tint variants fail. Human approval is still needed for taste. Local schema or prompt checks cannot award any score.

Critical failures include a different dog, moved identifying marks, impossible anatomy, a tennis ball/chasing scene, unprovided city/costume/food, invented personality object, generated lettering, incorrect exact note, or a result attributed to the wrong input. Preserve the failure evidence. Every returned output starts NOT QUALIFIED regardless of tool status.

Original-source export, native dimensions, print readability and matching production artifact are separate gates. A visually promising web derivative can advance the screen but cannot pass print acceptance. No physical quality claim follows from this test.
