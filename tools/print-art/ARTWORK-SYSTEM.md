The local request-state functions demonstrate the integration contract: selecting a tone makes no request, manual words are preserved with a rewrite offer, one deliberate action starts a pending request, an uncertain outcome survives serialization/reload, and another request is blocked until that outcome is reconciled. A stale response stays in evidence and cannot become the current preview unless the buyer returns to that exact input version. Switching among completed input versions reuses their receipts without another request. The last displayable preview remains separately available while choices are stale. `lastGood` means a structurally valid returned image, not accepted likeness or print quality. Purchase always remains disabled in this preparatory module.
