# Order quality control tools

The checks in this directory were built for a retired mug and cover none of the current products. The old mug pixel-calibration notes have moved to [`../../docs/history/ORDER-QC-README-2026-10.md`](../../docs/history/ORDER-QC-README-2026-10.md). Do not assume that an earlier photo-cutout layout validates the current landscape illustrated mug. `.github/workflows/order-qc.yml` still runs twice a day, but `order_qc.py` matches only line items titled "The Morning Mug", so it checks and tags no current order. `ORDER-QC-SETUP.md` describes that retired check. The portrait and blanket have no QC path. Until a checker for the current print layouts exists, the manual Teeinblue review is the only print check. [`../../NOW.md`](../../NOW.md) owns release state and [`../../docs/SCOPE.md`](../../docs/SCOPE.md) owns scope; the current order-linked print file and manual supplier review establish the production boundary.

Before using a QC script on a real order, inspect its source, input schema and fixtures against that product's current native print layout. Record what it checks and what it cannot establish. Automated checks cannot certify dog likeness or physical print quality.
