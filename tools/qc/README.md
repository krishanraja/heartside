# Order quality control tools

This directory contains historical and current checks with different coverage. The old mug pixel-calibration notes have moved to [`../../docs/history/ORDER-QC-README-2026-10.md`](../../docs/history/ORDER-QC-README-2026-10.md). Do not assume that an earlier photo-cutout layout validates the current landscape illustrated mug. [`../../NOW.md`](../../NOW.md) owns release state; the current order-linked print file and manual supplier review establish the production boundary.

Before using a QC script on a real order, inspect its source, input schema and fixtures against that product's current native print layout. Record what it checks and what it cannot establish. Automated checks cannot certify dog likeness or physical print quality.
